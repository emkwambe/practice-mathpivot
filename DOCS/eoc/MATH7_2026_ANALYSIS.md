- Prose choices render as plain text (never `\text{}` — nowrap KaTeX overflow bug fixed 2026-10-01)
- MC distractors: unique-set pre-check with redraw
- GR fraction answers must round-trip `checkAnswer` (`37/20` style)
- All `\\` double-backslashes in TS strings; run `scan_strings.py`
- EOG subjects stay out of Learn page; course registry entry + picker wiring + `MIXED_TECHNIQUE`
