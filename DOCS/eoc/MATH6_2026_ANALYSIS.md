## 1. Form profile

- 45 items total: **35 MC + 10 GR** (GR = Q11–20, the entire calculator-inactive tail + start of active section).
- Calculator Inactive: Q1–15 (10 MC + 5 GR).
- Calculator Active: Q16–45 (25 MC + 5 GR).
- GR entry: digits, `.`, `-`, `/` allowed; mixed numbers entered with a space ("941 11/64"); money answers as `dollars.cents` (e.g. `3.00`).
- Standards span 6.RP, 6.EE, 6.NS, 6.G, 6.SP (Grade 6 has no function/geometry-transformation content — much lighter than G7/G8).

## 7. Gotchas carried from math1/math3/math7/math8

- `context:` prose is **plain text** — no `\frac`, no `\$` (leaks raw LaTeX; caught by leak probe). LaTeX only in `question`/`choices`/`workShown` where KaTeX renders.
- MC money choices use `\\$` (choices are KaTeX-rendered); GR money answers are plain strings `"3.00"` (checkAnswer parseFloats, so `"3"` also matches — keep key format anyway).
- Every MC factory uses local `mcUnique(rng, correct, candidates, fallback)` — never bare `mc()` — to prevent distractor collisions.
- svgChoices items: answer is a letter `'A'..'D'`, `choices = ['A','B','C','D']`, SVGs rendered by the Practice UI (schema proven in math3/math7/math8).
- Q13/Q33 fraction arithmetic: answers like `"502"`, `"941 11/64"` — GR accepts `/` and mixed-number space format; keep fractions that terminate cleanly.
- Q19 rounding: mean 39.875 → key "39.88" — context must state "to the nearest cent".
- Q44 Venn consistency: color1-only + color2-only counts must each be ≥ 0 and the ratio (a+b):c must simplify; pick triples with gcd > 1.
- Q45 "approximately": correct choice must be the nearest integer to the exact rate; distractors far enough to avoid ambiguity.
- Nets: keep dimensions small integers; cross-layout coordinates precomputed in helper; labels upright.
- Dot plot: 8–12 data points, integer values; threshold question ("paid more than $X") must have an unambiguous count.
