## 5. Generator Module Map (Math 1)

App technique grouping for subject `math1-eoc` (7 techniques, each aggregating related item modules):

| Technique | Modules | Items covered |
|---|---|---|
| `m1-linear-equations` | solve ax+b=cx+d, distribute both sides, literal equations, budget inequalities, perimeter word problems | 3*, 9, 19, 20, 23 |
| `m1-systems` | solve 2×2, choose modeling system, inequality systems, classify solution count | 4, 5, 12, 25 |
| `m1-functions` | evaluate f(x), slope/intercept meaning, table → rule, recursive↔explicit, combine functions, initial value from table | 6–8, 10, 13, 21, 27, 31, 43 |
| `m1-quadratics-polynomials` | x²=c roots, projectile roots/vertex, factor forms, classify root signs, perimeter/area polynomial products | 3, 11, 16, 17, 26, 39, 45, 46 |
| `m1-exponentials` | growth rate, decay evaluation, linear-vs-exp, exceed point, intersection approx | 2, 18, 24, 37, 40, 47 |
| `m1-exponents-geometry` | exponent laws (N-RN.2), perpendicular/parallel, midpoint/endpoint, parallelogram slope+length | 14, 15, 32, 34, 35, 38, 41 |
| `m1-statistics` | best-fit predict/closest/farthest/model, correlation compute + describe, outlier effects, avg rate of change* | 22, 28–30, 33, 36, 44, 48–50 |

(*Q36/Q44 avg-rate-of-change could live in `m1-functions` instead — decide at build time.)

**Statistics generators need real computation in the generator:** linear regression (least squares), Pearson r, mean/median — all straightforward in TS. Generate 5–10 point datasets with controlled r (e.g., |r| ∈ {0.98…, 0.7…, 0.3…, negative}) and compute choices exactly.

## 6. Item-Type UI Requirements (new infrastructure)

Current MathPivot is free-response only. EOC format needs:

| Type | UI needed | Checker |
|---|---|---|
| MC | 4 choice cards A–D, click to select, KaTeX in choices | exact choice key |
| GR | numeric grid entry (digits, `.`, `-`, `/`) — reuse existing answer input minus palette | numeric/fraction equivalence (already have) |
| DD | classification: drag or tap-to-assign items into 2–3 columns | set mapping compare |
| TD | build expression from option banks (dropdowns per slot) — simplify to slot selects | slot tuple compare |

**Template schema extension** (additive, backward compatible):
```ts
interface ProblemTemplate {
  question: string; answer: string; steps: Step[]; hints: string[]; timeEstimate: number;
  itemType?: 'FR' | 'MC' | 'GR' | 'DD' | 'TD';   // default 'FR'
  choices?: string[];                            // MC: [A..D], answer = correct choice latex
  columns?: string[];                            // DD: column headers
  slots?: string[][];                            // TD: option bank per slot
}
```
