## 7. Gotchas carried from math1/math3/math7

- Long prose choices ("The slope means…") must be **plain text**, never `\text{}` — KaTeX nowrap overflows MC cards.
- GR decimal answers: accept `0.1` == `.1`, `3.5` == `3.50`; negative GR answers exist (`-12`) — the answer-checker must handle leading minus.
- `mc()` throws on duplicate distractors → unique-set pre-check + redraw (especially scatterplot-association: ensure the 3 wrong associations differ visually AND by label).
- TS strings: `\\` for every LaTeX backslash — run `python scan_strings.py` on all new files.
- VIS screenshots via probe_svg_strict (svg childElementCount > 8) — lucide icons false-positive the naive check.
- New SVG helpers go in a shared `svg.ts` style module; scatterplotSvg + polygonPlaneSvg + transversalSvg + exteriorAngleSvg + qualitativeGraphSvg are new for math8.
