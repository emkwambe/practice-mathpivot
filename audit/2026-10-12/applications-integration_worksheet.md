# applications-integration — independent audit worksheet

## Q1 (Area Between Curves — easy)

$$\text{Find the area of the region enclosed by } y = x \text{ and } y = x^2\text{.}$$

## Q2 (Area Between Curves — medium)

$$\text{Find the area of the region bounded by } y = x^2 - 2x \text{ and the } x\text{-axis} \\ \text{on the interval } [0, 2]\text{.}$$

## Q3 (Area Between Curves — hard)

$$\text{Find the area of the region enclosed by } x = y^2 \text{ and } x = 2 - y^2 \\ \text{(integrate with respect to } y\text{).}$$

## Q4 (Volumes of Revolution — easy)

$$\text{The region under } y = 2 \text{ on } [0, 3] \text{ is revolved about the } x\text{-axis.} \\ \text{Find the volume of the resulting cylinder.}$$

## Q5 (Volumes of Revolution — medium)

$$\text{The region under } y = x^2 \text{ on } [0, 2] \text{ is revolved about the } x\text{-axis.} \\ \text{Find the volume.}$$

## Q6 (Volumes of Revolution — hard)

$$\text{The region between } y = 2x \text{ and } y = x^2 \text{ on } [0, 2] \text{ is revolved about} \\ \text{the } x\text{-axis. Find the volume (washer method).}$$

## Q7 (Arc Length — easy)

$$\text{Find the arc length of } y = \frac{3}{4}x \text{ from } x = 0 \text{ to } x = 4\text{.}$$

## Q8 (Arc Length — medium)

$$\text{Find the arc length of } y = \frac{x^3}{3} + \frac{1}{4x} \text{ from } x = 1 \text{ to } x = 2\text{.}$$

## Q9 (Arc Length — hard)

$$\text{Find the arc length of } y = \frac{2}{3}x^{3/2} \text{ from } x = 3 \text{ to } x = 8\text{.}$$

## Q10 (Surface Area — easy)

$$\text{Find the surface area of a sphere of radius } 2 \text{ (surface area formula).}$$

## Q11 (Surface Area — medium)

$$\text{The curve } y = 2\sqrt{x} \text{ on } [0, 3] \text{ is revolved about the } x\text{-axis.} \\ \text{Find the surface area.}$$

## Q12 (Surface Area — hard)

$$\text{The curve } y = 2\sqrt{x} \text{ on } [3, 8] \text{ is revolved about the } x\text{-axis.} \\ \text{Find the surface area.}$$

## Q13 (Work & Physics — easy)

$$\text{A constant force of } 30 \text{ N moves an object } 4 \text{ m.} \\ \text{Find the work done (in joules).}$$

## Q14 (Work & Physics — medium)

$$\text{A } 20 \text{ m cable weighing } 50 \text{ N/m hangs from a winch. Find the work (in joules)} \\ \text{required to wind up the entire cable.}$$

## Q15 (Work & Physics — hard)

$$\text{A } 40 \text{ m chain weighing } 19.6 \text{ N/m hangs over the edge of a building.} \\ \text{Find the work (in joules) to pull the entire chain to the top.}$$

## Q16 (Center of Mass — easy)

$$\text{Masses of } 2 \text{ kg and } 3 \text{ kg sit at } x = 1 \text{ and } x = 5 \text{ on a rod.} \\ \text{Find the center of mass } \bar{x}\text{.}$$

## Q17 (Center of Mass — medium)

$$\text{Find the } x\text{-coordinate of the centroid of the region under } y = x^2 \\ \text{on } [0, 3]\text{.}$$

## Q18 (Center of Mass — hard)

$$\text{Find the } x\text{-coordinate of the centroid of the region under } y = \sqrt{x} \\ \text{on } [0, 4]\text{.}$$

## Q19 (Averages & Probability — easy)

$$\text{Find the average value of } f(x) = 2x + 1 \text{ on the interval } [0, 2]\text{.}$$

## Q20 (Averages & Probability — medium)

$$\text{A random variable has density } f(x) = \frac{3}{64}x^2 \text{ on } [0, 4]\text{.} \\ \text{Find its expected value } E[X]\text{.}$$

## Q21 (Averages & Probability — hard)

$$\text{A random variable has density } f(x) = \frac{3}{4}x(2 - x) \text{ on } [0, 2]\text{.} \\ \text{Find its variance } \text{Var}(X)\text{.}$$
