# sequences-series — independent audit worksheet

## Q1 (Geometric Series — easy)

$$\text{Find the sum of } 3 + 1 + \frac{1}{3} + \frac{1}{9} + \cdots\text{.}$$

## Q2 (Geometric Series — medium)

$$\text{Find the sum of } \sum_{n=0}^{\infty} \frac{3^n}{4^{n+1}}\text{.}$$

## Q3 (Geometric Series — hard)

$$\text{Find the sum of } \sum_{n=0}^{\infty} \frac{2^{n+1}}{5^n}\text{.}$$

## Q4 (P-Series & Telescoping — easy)

$$\text{Does } \sum_{n=1}^{\infty} \frac{1}{\sqrt{n}}\text{ converge or diverge?}$$

## Q5 (P-Series & Telescoping — medium)

$$\text{Find the sum of the telescoping series } \sum_{n=1}^{\infty} \frac{1}{n(n+1)}\text{.}$$

## Q6 (P-Series & Telescoping — hard)

$$\text{Find the sum of } \sum_{n=1}^{\infty} \left(\frac{1}{n+1} - \frac{1}{n+3}\right)\text{.}$$

## Q7 (Divergence Test — easy)

$$\text{Does } \sum_{n=1}^{\infty} \frac{n}{n+1}\text{ converge or diverge?}$$

## Q8 (Divergence Test — medium)

$$\text{Does } \sum_{n=1}^{\infty} \cos\!\left(\frac{1}{n}\right)\text{ converge or diverge?}$$

## Q9 (Divergence Test — hard)

$$\text{Does } \sum_{n=1}^{\infty} \frac{n!}{100^n}\text{ converge or diverge?}$$

## Q10 (Ratio Test — easy)

$$\text{For } \sum_{n=1}^{\infty} \frac{3^n}{n!}\text{, compute } L = \lim_{n \to \infty} \left| \frac{a_{n+1}}{a_n} \right|\text{.}$$

## Q11 (Ratio Test — medium)

$$\text{Does } \sum_{n=1}^{\infty} \frac{5^n}{n!}\text{ converge or diverge?}$$

## Q12 (Ratio Test — hard)

$$\text{Does } \sum_{n=1}^{\infty} \frac{4^n}{n \cdot 3^n}\text{ converge or diverge?}$$

## Q13 (Root Test — easy)

$$\text{For } \sum_{n=1}^{\infty} \frac{1}{2^n}\text{, compute } L = \lim_{n \to \infty} \sqrt[n]{|a_n|}\text{.}$$

## Q14 (Root Test — medium)

$$\text{Does } \sum_{n=1}^{\infty} \left(\frac{3n+1}{n+4}\right)^n\text{ converge or diverge?}$$

## Q15 (Root Test — hard)

$$\text{Does } \sum_{n=1}^{\infty} \left(\frac{n+1}{2n}\right)^n\text{ converge or diverge?}$$

## Q16 (Comparison Tests — easy)

$$\text{Does } \sum_{n=1}^{\infty} \frac{1}{n + 1}\text{ converge or diverge (compare with the harmonic series)?}$$

## Q17 (Comparison Tests — medium)

$$\text{Does } \sum_{n=2}^{\infty} \frac{1}{n^2 - 3}\text{ converge or diverge?}$$

## Q18 (Comparison Tests — hard)

$$\text{Does } \sum_{n=1}^{\infty} \frac{n^2 + 1}{n^4 + 3n}\text{ converge or diverge?}$$

## Q19 (Alternating Series — easy)

$$\text{The alternating series } \sum_{n=1}^{\infty} \frac{(-1)^{n+1}}{2n - 1} = 1 - \frac{1}{3} + \frac{1}{5} - \cdots \\ \text{is the Leibniz series. Find its exact sum.}$$

## Q20 (Alternating Series — medium)

$$\text{Does } \sum_{n=1}^{\infty} \frac{(-1)^n \, n}{n + 1}\text{ converge or diverge?}$$

## Q21 (Alternating Series — hard)

$$\text{Classify } \sum_{n=1}^{\infty} \frac{(-1)^n (n + 1)}{n^2}\text{: converges absolutely,} \\ \text{conditionally convergent, or divergent?}$$

## Q22 (Power Series — easy)

$$\text{Find the radius of convergence of } \sum_{n=0}^{\infty} \frac{x^n}{n!}\text{.}$$

## Q23 (Power Series — medium)

$$\text{Find the radius of convergence of } \sum_{n=1}^{\infty} \frac{(x - 2)^n}{n^2}\text{.}$$

## Q24 (Power Series — hard)

$$\text{In the Maclaurin series } e^x = \sum_{n=0}^{\infty} c_n x^n\text{, find } c_4\text{.}$$
