# applications-derivatives — independent audit worksheet

## Q1 (Optimization — easy)

$$\text{Two positive numbers have a sum of } 36. \text{ What should each number be} \\ \text{so that their product is as large as possible?}$$

## Q2 (Optimization — medium)

$$\text{One positive number plus twice a second positive number equals } 48. \\ \text{Find the first number } x \text{ that maximizes the product of the two numbers.}$$

## Q3 (Optimization — hard)

$$\text{An open-top box with a square base must hold } 32 \text{ m}^3\text{. Let } x \text{ be the side} \\ \text{length of the base. Find } x \text{ that minimizes the amount of material (surface area).}$$

## Q4 (Related Rates — easy)

$$\text{Suppose } y = x^2 \text{ and } x \text{ is increasing at } 5 \text{ units per second.} \\ \text{How fast is } y \text{ increasing when } x = 3\text{?}$$

## Q5 (Related Rates — medium)

$$\text{A } 5 \text{ m ladder leans against a wall. The bottom slides away from the wall at} \\ 1 \text{ m/s. Let } y \text{ be the height of the top of the ladder. Find } \frac{dy}{dt} \text{ (in m/s)} \\ \text{when the bottom is } 3 \text{ m from the wall.}$$

## Q6 (Related Rates — hard)

$$\text{A rocket rises vertically at } 200 \text{ m/s from a pad } 400 \text{ m from an observer.} \\ \text{How fast is the distance between the rocket and the observer increasing (m/s)} \\ \text{when the rocket is } 300 \text{ m high?}$$

## Q7 (Curve Sketching — easy)

$$\text{Find the } x\text{-coordinate of the critical point of } f(x) = x^2 - 4x + 3\text{.}$$

## Q8 (Curve Sketching — medium)

$$\text{How many critical points does } f(x) = x^4 - 2x^2 \text{ have?}$$

## Q9 (Curve Sketching — hard)

$$\text{Find the positive } x\text{-coordinate of an inflection point of } f(x) = x^4 - 6x^2\text{.}$$

## Q10 (Mean Value Theorem — easy)

$$\text{Find the value of } c \text{ guaranteed by Rolle's Theorem for} \\ f(x) = x^2 - 6x + 5 \text{ on the interval } [1, 5]\text{.}$$

## Q11 (Mean Value Theorem — medium)

$$\text{Find the value of } c \text{ guaranteed by the Mean Value Theorem for} \\ f(x) = 2x^2 + x \text{ on the interval } [1, 4]\text{.}$$

## Q12 (Mean Value Theorem — hard)

$$\text{Find the value of } c \text{ guaranteed by the Mean Value Theorem for} \\ f(x) = \ln(x) \text{ on the interval } [1, e]\text{.}$$

## Q13 (Linear Approximation — easy)

$$\text{Use the linear approximation of } f(x) = x^2 \text{ at } a = 1 \text{ to estimate } (1.1)^2\text{.}$$

## Q14 (Linear Approximation — medium)

$$\text{Use the linear approximation of } f(x) = \sin(x) \text{ at } a = 0 \text{ to estimate } \sin(0.1)\text{.}$$

## Q15 (Linear Approximation — hard)

$$\text{Use the linear approximation of } f(x) = \sqrt{x} \text{ at } a = 25 \text{ to estimate } \sqrt{24.6}\text{.}$$

## Q16 (Motion — easy)

$$\text{A particle has position } s(t) = 2t^2 \text{ (meters). Find its acceleration (in m/s}^2\text{)} \\ \text{at } t = 3\text{.}$$

## Q17 (Motion — medium)

$$\text{A particle has position } s(t) = t^3 - 9t^2 + 24t \text{ (meters). Find the total distance} \\ \text{(in meters) traveled from } t = 0 \text{ to } t = 3\text{.}$$

## Q18 (Motion — hard)

$$\text{A projectile has height } h(t) = -16t^2 + 96t \text{ (feet). Find its maximum height (feet).}$$

## Q19 (Economics — easy)

$$\text{A company earns revenue } R(x) = 20x \text{ dollars from selling } x \text{ units.} \\ \text{Find the marginal revenue (in dollars per unit).}$$

## Q20 (Economics — medium)

$$\text{The demand for a product is } p = 100 - 2x \text{ dollars per unit at } x \text{ units sold.} \\ \text{Find } x \text{ that maximizes the revenue.}$$

## Q21 (Economics — hard)

$$\text{The demand for a product is } p = 240 - 3x \text{ dollars per unit. Find the number of} \\ \text{units } x \text{ that maximizes revenue, and note that at the optimum the marginal} \\ \text{revenue equals zero.}$$
