# differentiation — independent audit worksheet

## Q1 (Basic Differentiation — easy)

$$\frac{d}{dx}\left(\frac{2}{x^3}\right)$$

## Q2 (Basic Differentiation — medium)

$$\frac{d}{dx}\left(\frac{x^4 + 2x}{x}\right)$$

## Q3 (Basic Differentiation — hard)

$$\frac{d}{dx}(\log_a x)$$

## Q4 (Product Rule — easy)

$$\frac{d}{dx}(x^3 \cdot \cos x)$$

## Q5 (Product Rule — medium)

$$\frac{d}{dx}(e^x \cdot \sin x)$$

## Q6 (Product Rule — hard)

$$\frac{d}{dx}[(x^2 + 1)(x + 2)(3x - 1)]$$

## Q7 (Quotient Rule — easy)

$$\frac{d}{dx}\left(\frac{1}{x^2 + 1}\right)$$

## Q8 (Quotient Rule — medium)

$$\frac{d}{dx}\left(\frac{x^2 + 1}{x^3 - x}\right)$$

## Q9 (Quotient Rule — hard)

$$\frac{d}{dx}\left(\frac{x^2 \sin x}{x + 1}\right)$$

## Q10 (Chain Rule — easy)

$$\frac{d}{dx}e^{2x}$$

## Q11 (Chain Rule — medium)

$$\frac{d}{dx}e^{x^2 + 3x}$$

## Q12 (Chain Rule — hard)

$$\frac{d}{dx}\left(\ln(\sin x)\right)^3$$

## Q13 (Implicit Differentiation — easy)

$$\text{Find } \frac{dy}{dx} \text{ if } xy = 4$$

## Q14 (Implicit Differentiation — medium)

$$\text{Find } \frac{dy}{dx} \text{ if } e^y = x + y$$

## Q15 (Implicit Differentiation — hard)

$$\text{Find } \frac{dy}{dx} \text{ if } \ln(x + y) = x^2 y$$

## Q16 (Logarithmic Differentiation — easy)

$$\text{Find } \frac{dy}{dx} \text{ if } y = x^x$$

## Q17 (Logarithmic Differentiation — medium)

$$\text{Find } \frac{dy}{dx} \text{ if } y = x^{x^2}$$

## Q18 (Logarithmic Differentiation — hard)

$$\text{Find } \frac{dy}{dx} \text{ if } y = x^{e^x}$$

## Q19 (Trigonometric Derivatives — easy)

$$\frac{d}{dx}(\sin^2 x + \cos^2 x)$$

## Q20 (Trigonometric Derivatives — medium)

$$\frac{d}{dx}\left(\frac{\sin x}{1 + \cos x}\right)$$

## Q21 (Trigonometric Derivatives — hard)

$$\frac{d}{dx}\left(\frac{1 - \tan x}{1 + \tan x}\right)$$

## Q22 (Higher-Order Derivatives — easy)

$$\text{Find } f'''(x) \text{ if } f(x) = e^x$$

## Q23 (Higher-Order Derivatives — medium)

$$\text{Find } f''(x) \text{ if } f(x) = \frac{1}{x}$$

## Q24 (Higher-Order Derivatives — hard)

$$\text{Find } f''(x) \text{ if } f(x) = \ln(x^2 + 1)$$
