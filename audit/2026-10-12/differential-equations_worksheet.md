# differential-equations — independent audit worksheet

## Q1 (Separable Equations — easy)

$$\text{Solve the initial value problem } \frac{dy}{dx} = y\text{, } y(0) = 5\text{.}$$

## Q2 (Separable Equations — medium)

$$\text{Solve } \frac{dy}{dx} = y^2\text{ with } y(0) = 1\text{, and find } y(-1)\text{.}$$

## Q3 (Separable Equations — hard)

$$\text{Solve } \frac{dy}{dx} = xy^2\text{ with } y(0) = -1\text{, and find } y(2)\text{.}$$

## Q4 (Linear First-Order — easy)

$$\text{Solve the initial value problem } y' + 2y = 0\text{, } y(0) = 3\text{.}$$

## Q5 (Linear First-Order — medium)

$$\text{Solve } y' + \frac{1}{x} y = x\text{ for } x > 0\text{ with } y(1) = 1\text{, and find } y(2)\text{.}$$

## Q6 (Linear First-Order — hard)

$$\text{Solve } y' + 2xy = 2x\text{ with } y(0) = 3\text{, and find } y(1)\text{.}$$

## Q7 (Homogeneous Equations — easy)

$$\text{Solve } \frac{dy}{dx} = \frac{y}{x}\text{ with } y(1) = 2\text{, and find } y(4)\text{.}$$

## Q8 (Homogeneous Equations — medium)

$$\text{Solve } \frac{dy}{dx} = \frac{x^2 + y^2}{2xy}\text{ with } y(1) = 0\text{, and find } y^2\text{ when } x = 4\text{.}$$

## Q9 (Homogeneous Equations — hard)

$$\text{Solve } \frac{dy}{dx} = \frac{x^2 + y^2}{xy}\text{ with } y(1) = 2\text{, and find } y^2\text{ when } x = e\text{.}$$

## Q10 (Exact Equations — easy)

$$\text{Is the equation } y \, dx + x \, dy = 0\text{ exact? Answer: exact or not exact.}$$

## Q11 (Exact Equations — medium)

$$\text{The equation } (3x^2 y + 2) \, dx + (x^3 + 2y) \, dy = 0\text{ is exact, with potential} \\ F(x, y) = x^3 y + 2x + y^2\text{. The solution through } (1, 1)\text{ satisfies } F = k\text{. Find } k\text{.}$$

## Q12 (Exact Equations — hard)

$$\text{The equation } (x + y^2) \, dx + (2xy + 3y^2) \, dy = 0\text{ is exact, with potential} \\ F(x, y) = \frac{x^2}{2} + xy^2 + y^3\text{. The solution through } (1, 0)\text{ satisfies } F = k\text{. Find } k\text{.}$$

## Q13 (Second-Order Constant Coefficients — easy)

$$\text{Solve } y'' + y = 0\text{ with } y(0) = 1\text{, } y'(0) = 0\text{.}$$

## Q14 (Second-Order Constant Coefficients — medium)

$$\text{Solve } y'' + 4y = 0\text{ with } y(0) = 0\text{, } y'(0) = 4\text{.}$$

## Q15 (Second-Order Constant Coefficients — hard)

$$\text{Solve } y'' + y' - 6y = 0\text{ with } y(0) = 1\text{, } y'(0) = 2\text{.}$$

## Q16 (Undetermined Coefficients — easy)

$$\text{Find a particular solution of } y'' + 3y' + 2y = 4\text{.}$$

## Q17 (Undetermined Coefficients — medium)

$$\text{Find a particular solution of } y'' + 2y' + y = 6e^x\text{.}$$

## Q18 (Undetermined Coefficients — hard)

$$\text{For } y'' + 4y = 8\cos(2x)\text{, a particular solution has the form } y_p = ax\sin(2x)\text{. Find } a\text{.}$$

## Q19 (Variation of Parameters — easy)

$$\text{Using variation of parameters, } y'' - y = e^x\text{ has a particular solution } y_p\text{. Find } y_p(1)\text{.}$$

## Q20 (Variation of Parameters — medium)

$$\text{Using variation of parameters, } y'' - 4y' + 4y = \frac{e^{2x}}{x^2}\text{ (}x > 0\text{) has a particular} \\ \text{solution } y_p = -e^{2x}(\ln(x) + 1)\text{. Find } y_p(1)\text{.}$$

## Q21 (Variation of Parameters — hard)

$$\text{Using variation of parameters, } y'' - 2y' + y = \frac{e^x}{x}\text{ (}x > 0\text{) has a particular} \\ \text{solution } y_p = xe^x(\ln(x) - 1)\text{. Find } y_p(1)\text{.}$$

## Q22 (Laplace Transforms — easy)

$$\text{Let } F(s) = \mathcal{L}\{f\}\text{ where } f(x) = \sin(2x)\text{. Find } F(0)\text{.}$$

## Q23 (Laplace Transforms — medium)

$$\text{Let } f\text{ be the inverse Laplace transform of } F(s) = \frac{1}{s - 2}\text{,} \\ \text{written as a function of } x\text{. Find } f(1)\text{.}$$

## Q24 (Laplace Transforms — hard)

$$\text{Let } f\text{ be the inverse Laplace transform of } F(s) = \frac{1}{s^2 + 2s + 5}\text{,} \\ \text{written as a function of } x\text{. Find } f\!\left(\frac{\pi}{4}\right)\text{.}$$
